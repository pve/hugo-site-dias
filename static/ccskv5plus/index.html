What is in CCSK?

CCSK covers cloud technology and governance, vendor-neutral. The workshop follows all twelve domains of the CSA CCSK Study Guide version 5, with introductory and deeper material around it. The exam topics are fully covered, and then some.

1. Cloud Computing Concepts and Architecture

2. Cloud Governance and Strategies

3. Risk, Audit and Compliance

4. Organization Management

5. Identity and Access Management

6. Security Monitoring

7. Infrastructure and Networking

8. Workload Security

9. Data Security

10. Application Security

11. Incident Response

12. Related Technologies

For the technical detail you work through the labs, hands-on, on the cloud platform of your choice: AWS or Azure.
